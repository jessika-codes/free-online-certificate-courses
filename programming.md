# Computer Science & Programming

Provider and course-directory links are starting points. Check the exact course page for current availability, fees, prerequisites, and credential conditions.

| Provider / resource | Official link | Learning and credential notes |
|---|---|---|
| freeCodeCamp | [https://www.freecodecamp.org/learn/](https://www.freecodecamp.org/learn/) | Free learning and free verified certifications for selected curricula; complete required projects/tests. |
| The Odin Project | [https://www.theodinproject.com/](https://www.theodinproject.com/) | Free open curriculum; completion is not a conventional provider-issued certificate. |
| Harvard CS50x | [https://cs50.harvard.edu/x/](https://cs50.harvard.edu/x/) | Free course access; free CS50 certificate may be available for qualifying completion, while edX verified certificate is paid. |
| Kaggle Learn | [https://www.kaggle.com/learn](https://www.kaggle.com/learn) | Free short courses with completion certificates for selected courses. |
| W3Schools | [https://www.w3schools.com/](https://www.w3schools.com/) | Free tutorials; many formal certificates/tests are paid. |
| Microsoft Learn | [https://learn.microsoft.com/training/](https://learn.microsoft.com/training/) | Free learning paths and achievement badges; role-based certification exams generally cost money. |
| Cisco Networking Academy | [https://www.netacad.com/](https://www.netacad.com/) | Free courses and selected completion certificates/badges; availability varies by course. |

## Before enrolling

- Confirm the course itself is currently available.
- Check whether the certificate, badge, assessment, or exam is free.
- Check regional eligibility, deadlines, language, and prerequisites.
- Record the date you verified the details when contributing an update.
